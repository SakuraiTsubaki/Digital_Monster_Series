# font-v0 source notice

This fallback font exists only to make the Emerald Japanese runtime renderable
while official/extracted project glyph assets are unavailable.

- M+ Bitmap Font: used for 639 of 642 extended glyphs.
- Ark Pixel Font 12px Mono zh_cn: used only for 泿, 砍, 觔.
- Official Digital Monster text/codepoints are not modified.
- The visual glyph shapes are explicitly non-canonical gameplay/bootstrap assets.

See M_PLUS_BITMAP_FONT_LICENSE.txt and ARK_PIXEL_FONT_OFL.txt.
