## 다국어 차이와 번역 문제

1. **비일본어 전체가 기계번역 가능 범위**다. 공식 페이지 자체 고지에 따라 한국어·영어·중국어 문구는 일본어 원문보다 낮은 신뢰도로 취급해야 한다.
2. **한국어 용어가 페이지 내부에서 일관되지 않다.** 도감 제목은 `아프몬`, 프로필 96건은 `어플몬`, 관련 블록 제목은 `관련 압몬은 이쪽`으로 표시된다. 프로필의 `어플몬` 사용 ID는 JSON과 마스터 CSV의 플래그로 남겼다.
3. **ID 121–126 속성 오역 가능성:** 일본어 `ゴッド`, 영어 `God`가 한국어에서 모두 `하나님`으로 표시된다. 분류명으로는 부자연스러운 기계번역으로 판단했다.
4. **ID 148 속성 의미 불일치:** 일본어 `不明`, 영어 `Unknown`인데 한국어는 `없음`이다. 같은 한국어 페이지의 그레이드는 `불명`이므로 속성 번역이 일관되지 않는다.
5. 명칭은 번역·음역 차이가 크지만 추측으로 수정하지 않았다. 마스터에는 각 공식 언어 페이지의 표시값을 그대로 보존했다.

## 이미지와 관계 데이터 예외

- 모든 ID에 캐릭터 일러스트가 상세 페이지에서 확인된다.
- ID 1–147은 아이콘도 상세 페이지에 표시된다.
- ID 148은 상세 페이지가 아이콘을 표시하지 않는다. 관례 경로 `https://digimon.net/cimages/appmon/img_icon_148.png` 자체는 별도 확인 시 HTTP 200이었지만, 페이지가 공식 이미지로 열거하지 않으므로 `icon_listed=false`로 기록했다.
- `関連するアプモンはこちら` 블록은 같은 페이지를 다시 요청했을 때 추천 ID 조합이 달라졌다. 따라서 이 블록은 공식 진화 관계가 아니라 **동적 관련 추천 스냅샷**으로 분류했다. 수집 당시 값은 보존했지만 진화·합체 관계로 해석하지 않았다.
